Conservative regridding now crops the source data to the domain before regridding. The wetlands and fire sectors read only that region from their inputs, which cuts the wetlands sector's peak memory from about 11 GB to 250 MB, and termite and livestock build smaller regridding weights. Cached regridding weights are now named after the source grid they were built for, so existing weights files are ignored and rebuilt once. Domains crossing the antimeridian, or lying west of Greenwich with a source whose longitudes run from 0° to 360° such as GFAS, now regrid correctly instead of missing source data.
